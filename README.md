# Ignisium

Ignisium is a cross-platform text editor component library written in Rust.

The project aims to provide a modern, extensible and long-term maintainable
text editing core.

## Goals

- Cross-platform
- High performance
- Extensible
- Stable core API
- Long-term API evolution

## Current Status

Early development.
